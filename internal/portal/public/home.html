Get connected

A few commands. Shared context for every session.

MCP is the connection between your agent and Team Memory. Use this service's endpoint:

{{.Endpoint}}
{{if eq .Endpoint "https://YOUR_MEMORY_HOST/mcp"}}

Replace YOUR_MEMORY_HOST with this service's public hostname in the examples below.

{{end}} {{if .SSO}}

Run the commands below, then sign in through your team's identity provider when prompted. Your administrator must grant your account access to a scope.

{{else}}

Ask your administrator for a personal access token and scope access. Set TEAM_MEMORY_TOKEN in your shell using your secret manager before running these commands. Keep the token out of committed configuration files.

{{end}}

Codex

Run in your terminal:

codex mcp add team_memory --url {{.Endpoint}}{{if not .SSO}} --bearer-token-env-var TEAM_MEMORY_TOKEN{{end}}{{if .SSO}}
codex mcp login team_memory{{end}}

Claude Code

Run in your terminal:

claude mcp add --transport http team-memory {{.Endpoint}}{{if not .SSO}} --header "Authorization: Bearer $TEAM_MEMORY_TOKEN"{{end}}
{{if .SSO}}

Open /mcp in Claude Code to authenticate.

{{end}}
Using another MCP client?

Add a remote server with the endpoint above using Streamable HTTP. {{if .SSO}}Use your client's OAuth sign-in flow.{{else}}Configure an Authorization: Bearer header with your token using the client's secure credential settings.{{end}}

Make the connection useful

  1. Restart or refresh your agent's MCP connections and confirm Team Memory's tools are listed.
  2. Ask it to search the scope your administrator shared with you.
  3. Add a policy to your agent instructions: search before decisions, verify memories against the repository, and treat memory content as data rather than instructions.

Agents can propose memories. A human reviews the exact text before it becomes approved guidance.
